This repository contains the code and instructions to reproduce the results of the article [**Bayesian network-informed conditional random forests for probabilistic multisite downscaling of precipitation occurrence**](https://doi.org/10.1016/j.envsoft.2026.106907), by Mikel N. Legasa, Richard E. Chandler, and R. Manzanas, published in _Environmental Modelling & Software_.

It contains three notebooks:
- Refer to _BNICRF - Worked Example and Reproducibility of Results.ipynb_ for instructions and reproducibility.
- In _BNICRF - Illustrative Example for 53 Locations.ipynb_, we show an illustrative example using 53 stations over Europe from the [European Climate Assessment & Dataset project](https://www.ecad.eu).
- In _Rglimclim Multi-Site GLM - Model Development and Reproducibility of Results.ipynb_ we reproduce the results for the spatial generalized linear model (GLM) used as a benchmark in the main article.

Note: Please refer to https://github.com/Richard-Chandler/Rglimclim and the article [**Chandler (2020)**](https://doi.org/10.1016/j.envsoft.2020.104867) for further details on the spatial GLM methodology.
